# Core Routine

A beginner core workout with glute bridges, clamshells, dead bug heel taps, and legs-only bird-dog slides. The app includes animations, linked video demonstrations, timed holds, and guided sets.

Exercise instructions and timing are in `routine.js`. The app saves completed sets in the browser.

## Run locally

From the repository folder, run `python3 -m http.server 8000` and open `http://localhost:8000`.

## Hosting

GitHub Pages serves the static files from the root of the `main` branch. The app uses relative paths, so it can run under the repository's Pages URL.
